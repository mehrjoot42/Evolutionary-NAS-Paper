# Beyond Architecture: Evolutionary Discovery of Topologies and Optimizers on CPU

This repository contains the official PyTorch implementation of the two-phase evolutionary framework described in the paper.

## 🌱 Green AI Highlights
- **Hardware:** Runs entirely on a standard CPU.
- **Efficiency:** Discovers DenseNet-style architecture and optimizer coefficients efficiently.
- **Stability:** Stable, dataset-agnostic optimizer rules.

## 🚀 How to Run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the main code: `python main.py`
